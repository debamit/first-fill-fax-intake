First-fill fax intake — logical architecture

Draft · 2026-11-09 · logical view, not a deployment view · nothing here is probed from a live system

The boundary that carries the load

  • The model emits fields; code calls every API; a human commits.
  • No tools, no credentials, no memory — an injected instruction has nothing to reach.
  • Prompt hardening and detectors are dampeners. This is the boundary.

Three error sources, three queues

  • Perception — a misread digit. Fixed by a second pass and provenance.
  • Adversarial — text that instructs. Fixed by removing agency.
  • Source document — a wrong Rx, perfectly legible. Fixed only by outside reconciliation.

What the model may never do

  • Choose first fill vs refill, or decide where anything goes.
  • Hold an order-API credential, or act on free text.
  • Auto-correct a source error. Substitution is a recorded human act.
